# report_notes/

Claude's working notebook for VSC — kept out of Marv's way on purpose.

**What's in here:** the careful stuff — how each experiment was set up, what result would have meant "no", where every number came from, caveats, and the things a report would need. It exists so that *if* Marv ever wants to write a report or a write-up, the provenance is already there.

**What it is not:** rules for Marv. Nothing here is required reading, and nothing here should leak into how sessions talk to him. The project's actual working agreement is `../agent.md`.

- `_v1_heavy_draft.md` — the first, over-formal draft of agent.md (26 Oct). Kept as Claude's own method notes: failure modes to watch, reporting habits, a pre-run checklist. Claude applies it quietly to its own experiments.
- `experiments/` — one note per experiment Claude runs (setup, the result that would have refuted it, the numbers, caveats). Added as experiments happen.
